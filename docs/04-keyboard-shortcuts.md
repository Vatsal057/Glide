# Global keyboard shortcuts

Beyond trackpad gestures, Glide can bind any of its actions to a **global keyboard shortcut** active across macOS. Configure these in **Preferences → Keyboard**.

Add a shortcut, record the key combination, and assign an action: all actions in [Every action, explained](03-actions.md) are supported. The combination requires at least one modifier key (⌘ ⌥ ⌃ ⇧) to distinguish it from standard text entry.

Because these are system-wide hotkeys, select combinations that do not overlap with existing applications. Glide verifies conflicts within its own rules.
