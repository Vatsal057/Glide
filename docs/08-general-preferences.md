# General preferences

**Preferences → General** controls application-wide behavior:

- **Accessibility Permission:** Status indicator confirming whether Glide has accessibility access, including a direct link to the corresponding macOS System Settings pane.
- **Window Targeting:** Selects whether window management actions target the currently focused window or the window located directly under the cursor.
- **Debug Logging:** Directs detailed gesture diagnostic logs to the system Console.
- **Launch at Login:** Configures Glide to start automatically upon user login.
- **Haptics:** Toggles Taptic Engine feedback and assigns custom haptic signatures (tick, tap, knock, double tap, rising, falling) to specific event categories. Selecting a pattern previews the tactile response.
- **macOS Gesture Conflicts:** Detects when a custom gesture shares an identical trigger with a native macOS system gesture. Glide can disable the conflicting system gesture directly, with options to re-enable system defaults at any point.
- **Stats:** Displays live counts of configured rules, active gestures, finger distributions, reciprocal pairs, modifier restrictions, and broken app paths.
- **Updates:** Queries GitHub for new releases, validates downloaded packages against published release checksums, and applies updates in place.
- **Welcome Tour:** Reruns the interactive first-launch onboarding sequence.
